# 《島口大開》實作提示詞

把以下內容交給負責程式的 session。

---

請在 `/workspace/mobileSensingGame` 實作《島口大開》的第一版。這是一款 3D 浮島動作遊戲，主玩法是雙人同屏合作打怪，也要能單人玩。沿用這個專案現有的 Node.js、WebSocket、QR Code 配對與 HTTPS 感測器流程，建立獨立的遊戲入口。

## 一局怎麼玩

- 每局約 5 分鐘。兩位見習修島員從相同的走位、跳躍與敲擊開始。
- 巨怪輪流盯上一位玩家。大螢幕在候選地磚上畫出咬痕，提前鎖定落點。被盯的玩家可以引導巨怪咬下想用的磚，搭檔趁巨怪卡住時從側邊敲擊。玩家要能從畫面看出磚會飛去哪裡。
- 被咬的地磚從島上消失，被敲出去後，在落點成為可踩的平台。第一版重點是引怪吃下彈簧磚，再把它打到斷橋旁。玩家踩彈簧磚跳上鐘樓，敲鐘打開巨怪防護，兩人趁機打核心。
- 弄丟彈簧磚或錯過窗口時，要能重來一輪。掉下島後令玩家在安全磚復活。單人模式給更長的敲磚與弱點窗口，讓玩家自己完成整個循環。
- 至少跑通一次完整循環，再加一個局內分流。兩位玩家起手相同，第一次敲鐘後可走上能力區，選「黏土靴」以落地固定相鄰平台，或選「回音槌」以延長敲磚距離。兩人可選同一能力，基本招仍足以通關。

## 控制與顯示

- 電腦螢幕顯示固定斜俯視 3D 場地，完整收進整座島，所有時間、提示和選擇都在這個畫面。
- 手機配對與授權完成後，玩家只看電腦螢幕。雙軸傾斜走位、手腕短抬跳躍、向前短推敲擊。校正用自然持握姿勢當基準，加入死區和動作冷卻。用實機確認兩個手勢不易互相誤觸。
- 藍與橘兩人各有清楚的頭頂標記。提供鍵盤除錯操作，方便先驗證單機、雙人與局末重開。
- 弱點、咬痕和落點要有不同形狀或動態提示，並可用程式畫。玩家走上場上的能力區完成選擇。

## 現有美術

模型在 `public/assets/island/`，可由 `/assets/island/` 載入。都是 GLB，使用 glTF 的 Y-up 座標。角色與巨怪面向 +Z。無貼圖依賴，動作由程式旋轉命名節點。

| 檔案 | 接法 |
|---|---|
| `repairer-blue.glb`、`repairer-orange.glb` | 同一角色、兩個配色，原點在腳下。使用 `Arm_L`、`Arm_R`、`Leg_L`、`Leg_R` 做跑跳與敲擊，右臂帶槌。 |
| `chomp-boss.glb` | 根節點 `Boss`。旋轉 `UpperJaw`、`Jaw` 表現張嘴和卡住。把地磚的展示模型掛在 `BrickSocket`，真正的地磚位置由遊戲邏輯處理。`Core` 是發光弱點，可切換可見性。 |
| `ground-tile.glb`、`spring-tile.glb` | 寬約 1.44，建議以 1.5 間距排格，中心原點在可站立的頂面。金色磚是彈簧磚。 |
| `bell-tower.glb` | 原點在底部，`BellPivot` 用於敲鐘動畫。能站的位置和碰撞範圍由程式定義。 |
| `art-preview.png` | 美術合成預覽，可參考鏡頭、配色和場地密度。 |

先驗收「咬掉一塊磚 → 敲出新平台 → 彈跳敲鐘 → 打中核心」，再確認一人與兩人都可完成、落空可以重試、所有遊戲提示留在電腦螢幕上。
