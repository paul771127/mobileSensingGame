# 手機體感遊戲（Mobile Sensing Game）

同一個伺服器提供兩款遊戲，都是「手機當控制器、電視 / 電腦當畫面」：

- 🎾 **手機球拍對戰** — `/display` + `/controller`（下方說明）
- 🏝 **島口大開** — `/island` + `/island/controller`（見 [《島口大開》](#-島口大開)）

# 🎾 手機球拍對戰

把手機當成球拍的體感對戰遊戲。手機透過瀏覽器讀取加速度計 / 陀螺儀偵測揮拍，
電視或電腦的瀏覽器顯示完整球場、雙方球員與球的飛行；同一個房號可以在**多台螢幕**同時開啟顯示端，
雙方各看各的螢幕（各自的視角）對戰。不需要安裝 App。

```
手機 A ──┐                        ┌── 螢幕 1（A 視角）
         ├─ WebSocket ─ 伺服器 ───┼── 螢幕 2（B 視角）
手機 B ──┘   （物理 / 規則）       └── 螢幕 3（俯視）
```

## 快速開始

```bash
npm install
npm start
```

1. 電視或電腦開 `http://<伺服器IP>:8443/display`，畫面會顯示房號與 QR code。
2. 兩支手機掃 QR code（或開 `/controller` 輸入房號），選 A 方或 B 方，按「加入並開啟感測器」。
3. 兩人都加入後自動開始。發球方揮手機發球，之後球飛向誰，誰就在球接近時揮拍。
4. 要多螢幕：在其他裝置開 `http://<伺服器IP>:8443/display?room=房號&side=B`（`side` 可為 `A`、`B`、`top`）。

顯示端快捷鍵：`F` 全螢幕、`R` 重新開始。手機上也可以「點一下揮拍」（桌機測試用空白鍵）。

## iPhone 需要 HTTPS

iOS Safari 只允許 HTTPS 網頁讀取動作感測器。區網測試請用 [mkcert](https://github.com/FiloSottile/mkcert) 產生憑證：

```bash
mkcert -install
mkdir -p certs
mkcert -key-file certs/key.pem -cert-file certs/cert.pem localhost 192.168.x.x
npm start
```

`certs/` 裡有 `key.pem` 與 `cert.pem` 時伺服器會自動改用 HTTPS（同一個 8443 埠）。
手機要先安裝 mkcert 的根憑證（iOS：設定 → 一般 → VPN 與裝置管理，然後在「憑證信任設定」開啟）。
也可以直接部署到任何提供 HTTPS 的主機（Render、Fly.io、Railway 等），用 `PORT` 環境變數指定埠。

## 遊戲機制

- **揮拍偵測**（`public/controller.js`）：加速度大小超過門檻進入揮拍、低於門檻後送出一次 `swing`，包含六個參數：
  - `strength` 力道：加速度峰值。
  - `dirX` 揮動方向：陀螺儀繞手機長軸。
  - `face` 拍面角度：由 DeviceOrientation 建旋轉矩陣，取螢幕法線的水平方位，相對「加入時 / 按校正時正對電視」的基準，±45° 對應 ±1。
  - `loft` 拍面仰角：螢幕法線的垂直分量，手機往後躺就是開拍面。
  - `plane` 揮拍平面：揮拍加速階段的加速度向量轉到世界座標，看垂直與水平的夾角，由下往上撈為正、由上往下劈為負。
  - `spin` 手腕翻轉：陀螺儀繞手機短軸，往下壓上旋、往上甩下旋。
  - `curve` 側旋：陀螺儀繞螢幕法線（像削球那樣側向刷）。

  可調靈敏度、左右鏡像、重新校正拍面方向。桌機測試：空白鍵平擊、↑ 撈球、↓ 劈球、← → 拍面左右、Z 上旋、X 下旋、Q/E 側旋、WASD 移動。
- **開局校正**：按加入後先進入校正畫面，用準備姿勢握手機、正對電視按「完成校正」。這個姿勢是拍面方向與移動的基準。
- **跑位（手機平移）**：去重力加速度轉到世界座標後積分成手機位移（靜止歸零速度、揮拍中暫停、限 ±35 cm），手機 30 cm 對應球場左右 ±5 m、前後 ±3.5 m；角色以 9 m/s 追上目標點。來球最後 0.7 秒目標點向球靠近一半（輔助）。每一分開始位移歸零。`TRANSLATE_MOVE` 旗標可關閉回到全自動。
- **物理與規則**（`server/game.js`）：伺服器權威。球有 3D 位置與重力、過網判定、落地出界判定、
  兩次落地失分。擊球時：
  - 落點左右 = 拍面角度（主）+ 揮動方向（輔），以球員自己的左右為準（A、B 自動對稱）。
  - 弧線 = 揮拍平面（主）+ 拍面仰角 + 手腕翻轉。撈球較慢、較高、較深；劈球較快、較平、更深，時機差就掛網。
  - 擊球時機（球距理想擊球點的誤差）影響深度與左右，太早太晚就出界或掛網。
  - 旋球用馬格努斯效應呈現：上旋出手較高、空中明顯下墜、落地彈高往前竄；下旋出手平、空中飄、落地低且慢；側旋在空中側向彎。拖尾顏色：上旋橘、下旋藍、側旋紫。

  網球計分（0/15/30/40/Ad，6 局勝）。
- **球員移動**：手機無法定位真實位置，採自動跑位（Wii Sports 式），移動為 8 方向並有走路動畫。
- **落點**：輕揮約 2.5 m 的網前短球，全力約 10 m；壓線算進（球心超出線外 12 cm 內都算界內）。
- **顯示端**（`public/display.js`）：Canvas 2D，A/B 視角是從球員後上方的透視投影（俯視球場圖用水平條帶貼到地面），`top` 為俯視。30 Hz 狀態廣播 + 本地外插。

# 🏝 島口大開

3D 浮島合作動作遊戲：兩位見習修島員（藍、橘）在同一個電腦畫面上合作，引巨怪咬磚、把磚敲成新平台、
彈上鐘樓敲鐘打開防護、兩人一起打核心。**一個人也能玩**（敲磚與弱點窗口自動加長）。

```bash
npm install
npm start
```

1. 電腦開 `http://<伺服器IP>:8443/island`，畫面上有房號與 QR code。
2. 手機掃 QR code（或開 `/island/controller` 輸入房號），選藍或橘，按「加入並開啟感測器」，
   以**自然持握姿勢**（像拿遙控器）正對螢幕按「完成校正」。
3. 配對完成後只看電腦螢幕。任一人**向前短推**開始；遊戲中隨時可以第二支手機加入。
4. **只有一個人？** 手機大廳按「讓電腦當搭檔」，或在電腦上按 `B`，電腦玩家會占用空位；之後有真人加入會自動讓位。

## 一局怎麼玩（約 5 分鐘）

1. **引怪**：巨怪輪流盯上一位玩家，畫面在候選地磚畫出白色咬痕、鎖定時變紅色。被盯的人站上
   **金色彈簧磚**，紅色鎖定出現就跳開（留在磚上會跟著磚一起掉下去）。
2. **敲飛**：巨怪咬住磚後會卡住（雙人 3.5 秒、單人 6.5 秒）。站在它側邊向前短推敲它，
   磚會朝「遠離你」的方向飛 4 格；黃色方框 + 虛線弧線就是落點預覽，落點進到斷橋虛線格會變綠 ✓。
   被敲出去的磚落地後成為可踩的平台（落在原有地磚上就是高半格的台階）。
3. **上塔敲鐘**：踩落在斷橋旁的彈簧磚會高高彈起，空中傾斜朝鐘樓，落在平台上向前短推敲鐘。
   巨怪防護打開（雙人 8 秒、單人 15 秒），粉紅核心與六角弱點標記出現。
4. **打核心**：靠近巨怪嘴前的核心向前短推，共 5 下即勝利。時間到則失敗。
5. **重來一輪**：沒人敲 → 磚被吞掉；飛出島外 → 掉進海裡；平台鬆動 30 秒後崩落。這些情況彈簧磚都會在
   8 秒後長回原位（一般地磚 25 秒）。掉下島的玩家 1.5 秒後在安全磚復活。
6. **能力分流**：第一次敲鐘後島上出現兩個能力區，站上去 1 秒選擇：
   - **黏土靴**：落地時把相鄰（含腳下）的鬆動平台固定住，不再崩落。
   - **回音槌**：敲擊距離 1.7 → 2.9，敲磚、敲鐘、打核心都更遠。
   兩人可以選同一個，也可以不選；基本招式足以通關。

## 電腦搭檔

`server/island.js` 的 `botThink()` 每 tick 依狀況分工，只用和真人一樣的走 / 跳 / 敲輸入：

- 你被盯上：先走到預計咬點的側邊待命；巨怪咬住後約 0.8 秒（留給你先敲的機會）從能把磚敲進斷橋區的角度敲它。
- 它被盯上：自己站上彈簧磚引怪，紅色鎖定出現就往遠離巨怪的鄰磚跳開。
- 彈簧磚就位：離平台近的那個去彈、敲鐘，另一個先到核心前站位；防護打開就一起打核心（在塔上會自己跳下來）。
- 鐘響後沒能力時去拿回音槌；閒置時站在彈簧磚南邊一格。
- 走路用 BFS 只踩有磚的格子，不會自己走進洞；被敲掉的磚前面站不住時會換一個敲得到的位置。

窗口長度（卡住 / 防護）以**真人數**計算，電腦搭檔不會把窗口縮短。

## 控制

| 動作 | 手機 | 鍵盤除錯（顯示端） |
|---|---|---|
| 走位 | 雙軸傾斜（死區 6°、24° 全速，基準 = 校正時的持握姿勢） | 藍 WASD ／ 橘 方向鍵 |
| 跳躍 | 手腕短促上抬 | 藍 空白 ／ 橘 Enter |
| 敲擊 | 向前短推 | 藍 E ／ 橘 右 Shift |
| 其他 | 「重新校正持握」、手勢靈敏度、前後 / 左右反轉、點擊備援按鈕、大廳「讓電腦當搭檔」 | 1 / 2 加入鍵盤玩家、B 電腦搭檔、R 重開、F 全螢幕 |

手勢判定（`public/island/controller.js`）：去重力加速度轉到世界座標，超過門檻進入「爆發」，累積加速階段的向量，
峰值一過就分類——**向上分量占優**為跳躍、**沿手機前方的水平分量占優**為敲擊，其餘忽略；跳躍 450 ms、
敲擊 350 ms 冷卻，任一手勢後 250 ms 內互斥，手勢期間姿態傾斜不更新走位。門檻與相互誤觸請在實機上
用畫面左下的除錯數值（`up / fwd / lat`）調整。iPhone 一樣需要 HTTPS（見上方 mkcert 說明）。

## 美術模型

模型放在 `public/assets/island/`（glTF Y-up，角色與巨怪面向 +Z），**缺檔時程式會自動用同名節點的替代模型**，
所以沒有 GLB 也能跑，放進去就會自動載入：

| 檔案 | 程式接法 |
|---|---|
| `repairer-blue.glb`、`repairer-orange.glb` | 原點在腳下；旋轉 `Arm_L`、`Arm_R`、`Leg_L`、`Leg_R` 做跑跳與敲擊（右臂帶槌） |
| `chomp-boss.glb` | 根節點 `Boss`；`UpperJaw` / `Jaw` 張嘴與卡住；咬住的磚掛在 `BrickSocket`；`Core` 只在防護打開時可見 |
| `ground-tile.glb`、`spring-tile.glb` | 1.5 間距排格，原點在可站立的頂面 |
| `bell-tower.glb` | 原點在底部；`BellPivot` 做敲鐘擺動。可站平台（高 3.2、半徑 1.35）由 `server/island.js` 的 `TOWER` 定義 |

Three.js 由伺服器從 `node_modules/three` 以 `/vendor/three/…` 提供，區網沒有對外網路也能用。

## 測試

```bash
npm test
```

`test/island-loop.test.mjs` 用腳本玩家在無頭模擬裡跑完整循環：單人與雙人各一次（引怪 → 敲飛到斷橋 →
彈上鐘樓 → 敲鐘 → 打核心 → 勝利），以及落空長回、掉島復活、錯過窗口被吞、能力區選擇、真人 + 電腦搭檔完整循環、
電腦被盯上時自己引怪跳開。

### 巨怪階段、特殊招式、小怪與電腦個性

- **三階段**：巨怪 9 滴血、每 3 滴一段。打掉一段防護就提前合上並怒吼震波，鐘聲也會把彈簧平台震落，要重新引怪再跑一輪；越後面節奏越快。
- **特殊招式**（每咬一口之後接一招）：震地（紅色波紋掃到腳邊時跳起來躲）、直線衝撞（第二階段起，離開紅色通道）、召喚小怪。咬擊落點旁的人也會被撞飛。
- **小怪**：爪爪怪（追人近戰）、浮游晶（第二階段起，遠距光球，可跳過或敲掉）、衝撞精英（第三階段，瞄準後直衝，可引牠衝出島外）。靠近敲擊即可打倒。
- **電腦搭檔個性**：上場時隨機抽「穩健 / 急性子 / 獵人 / 謹慎」，反應速度、會不會搶鐘、追不追小怪、選哪個能力都不同，名稱顯示在玩家卡上。
- 測試用：`new IslandGame({ specials, mobs, phases, seed })` 可關掉上述規則或固定亂數。
