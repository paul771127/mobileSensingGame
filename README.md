# 手機體感遊戲（Mobile Sensing Game）

同一個伺服器提供兩款遊戲，都是「手機當控制器、電視 / 電腦當畫面」：

- 🎾 **手機球拍對戰** — `/display` + `/controller`（下方說明）
- 🏝 **島口大開** — `/island` + `/island/controller`（見 [《島口大開》](#-島口大開)）

# 🎾 手機球拍對戰

把手機當成球拍的體感對戰遊戲。手機透過瀏覽器讀取加速度計 / 陀螺儀偵測揮拍，
電視或電腦的瀏覽器顯示完整球場、雙方球員與球的飛行；同一個房號可以在**多台螢幕**同時開啟顯示端，
雙方各看各的螢幕（各自的視角）對戰。不需要安裝 App。

```
手機 A ──┐                        ┌── 螢幕 1（A 視角）
         ├─ WebSocket ─ 伺服器 ───┼── 螢幕 2（B 視角）
手機 B ──┘   （物理 / 規則）       └── 螢幕 3（俯視）
```

## 快速開始

```bash
npm install
npm start
```

1. 電視或電腦開 `http://<伺服器IP>:8443/display`，畫面會顯示房號與 QR code。
2. 兩支手機掃 QR code（或開 `/controller` 輸入房號），選 A 方或 B 方，按「加入並開啟感測器」。
3. 兩人都加入後自動開始。發球方揮手機發球，之後球飛向誰，誰就在球接近時揮拍。
4. 要多螢幕：在其他裝置開 `http://<伺服器IP>:8443/display?room=房號&side=B`（`side` 可為 `A`、`B`、`top`）。

顯示端快捷鍵：`F` 全螢幕、`R` 重新開始。手機上也可以「點一下揮拍」（桌機測試用空白鍵）。

## iPhone 需要 HTTPS

iOS Safari 只允許 HTTPS 網頁讀取動作感測器。區網測試請用 [mkcert](https://github.com/FiloSottile/mkcert) 產生憑證：

```bash
mkcert -install
mkdir -p certs
mkcert -key-file certs/key.pem -cert-file certs/cert.pem localhost 192.168.x.x
npm start
```

`certs/` 裡有 `key.pem` 與 `cert.pem` 時伺服器會自動改用 HTTPS（同一個 8443 埠）。
手機要先安裝 mkcert 的根憑證（iOS：設定 → 一般 → VPN 與裝置管理，然後在「憑證信任設定」開啟）。
也可以直接部署到任何提供 HTTPS 的主機（Render、Fly.io、Railway 等），用 `PORT` 環境變數指定埠。

## 遊戲機制

- **揮拍偵測**（`public/controller.js`）：加速度大小超過門檻進入揮拍、低於門檻後送出一次 `swing`，包含六個參數：
  - `strength` 力道：加速度峰值。
  - `dirX` 揮動方向：陀螺儀繞手機長軸。
  - `face` 拍面角度：由 DeviceOrientation 建旋轉矩陣，取螢幕法線的水平方位，相對「加入時 / 按校正時正對電視」的基準，±45° 對應 ±1。
  - `loft` 拍面仰角：螢幕法線的垂直分量，手機往後躺就是開拍面。
  - `plane` 揮拍平面：揮拍加速階段的加速度向量轉到世界座標，看垂直與水平的夾角，由下往上撈為正、由上往下劈為負。
  - `spin` 手腕翻轉：陀螺儀繞手機短軸，往下壓上旋、往上甩下旋。
  - `curve` 側旋：陀螺儀繞螢幕法線（像削球那樣側向刷）。

  可調靈敏度、左右鏡像、重新校正拍面方向。桌機測試：空白鍵平擊、↑ 撈球、↓ 劈球、← → 拍面左右、Z 上旋、X 下旋、Q/E 側旋、WASD 移動。
- **開局校正**：按加入後先進入校正畫面，用準備姿勢握手機、正對電視按「完成校正」。這個姿勢是拍面方向與移動的基準。
- **跑位（手機平移）**：去重力加速度轉到世界座標後積分成手機位移（靜止歸零速度、揮拍中暫停、限 ±35 cm），手機 30 cm 對應球場左右 ±5 m、前後 ±3.5 m；角色以 9 m/s 追上目標點。來球最後 0.7 秒目標點向球靠近一半（輔助）。每一分開始位移歸零。`TRANSLATE_MOVE` 旗標可關閉回到全自動。
- **物理與規則**（`server/game.js`）：伺服器權威。球有 3D 位置與重力、過網判定、落地出界判定、
  兩次落地失分。擊球時：
  - 落點左右 = 拍面角度（主）+ 揮動方向（輔），以球員自己的左右為準（A、B 自動對稱）。
  - 弧線 = 揮拍平面（主）+ 拍面仰角 + 手腕翻轉。撈球較慢、較高、較深；劈球較快、較平、更深，時機差就掛網。
  - 擊球時機（球距理想擊球點的誤差）影響深度與左右，太早太晚就出界或掛網。
  - 旋球用馬格努斯效應呈現：上旋出手較高、空中明顯下墜、落地彈高往前竄；下旋出手平、空中飄、落地低且慢；側旋在空中側向彎。拖尾顏色：上旋橘、下旋藍、側旋紫。

  網球計分（0/15/30/40/Ad，6 局勝）。
- **球員移動**：手機無法定位真實位置，採自動跑位（Wii Sports 式），移動為 8 方向並有走路動畫。
- **落點**：輕揮約 2.5 m 的網前短球，全力約 10 m；壓線算進（球心超出線外 12 cm 內都算界內）。
- **顯示端**（`public/display.js`）：Canvas 2D，A/B 視角是從球員後上方的透視投影（俯視球場圖用水平條帶貼到地面），`top` 為俯視。30 Hz 狀態廣播 + 本地外插。

## 專案結構

```
server/index.js             HTTP(S) 靜態檔 + WebSocket 房間 + 60Hz 主迴圈（兩款遊戲共用）

server/island.js            島口大開：浮島、巨怪狀態機、飛磚、鐘樓 / 核心、能力區
public/index.html           入口
public/display.*            球拍對戰顯示端
public/controller.*         球拍對戰手機控制器
public/island/display.*     島口大開顯示端（Three.js，固定斜俯視 3D）
public/island/controller.*  島口大開手機控制器（傾斜 / 上抬 / 前推）
public/common.js            WebSocket 重連、資源載入
public/assets/              美術資源（球拍：manifest.json；島口大開：assets/island/*.glb）
test/island-loop.test.mjs   島口大開無頭模擬測試（npm test）
docs/                       工單與文件
```

# 🏝 島口大開

1～4 人同屏合作闖關的 3D 浮島動作遊戲：三個小關清怪、全隊共用擊倒計數升級選技能、最後合力擊碎方塊巨怪的核心。
手機傾斜走位、手腕短抬跳躍，靠近敵人會自動敲；配對完成後全程只看電腦螢幕。

```bash
npm install
npm start
```

1. 電腦開 `http://<伺服器IP>:8443/island`，畫面上有房號與 QR code。
2. 手機掃 QR code（或開 `/island/controller` 輸入房號），選顏色或自動分配，按「加入並開啟感測器」，
   像拿遙控器一樣往前傾約 45° 握著，正對螢幕按「開始」。最多 4 人，遊戲中也可以中途加入。
3. 任一人**向前短推**手機開始（鍵盤 E）。

## 一局怎麼玩（約 8～12 分鐘）

| 階段 | 內容 |
|---|---|
| 第一關 荒磚岸 | 三波近戰小怪，熟悉走位與自動攻擊 |
| 第二關 回音灘 | 加入會保持距離射擊的遠程怪，隊伍有理由分頭處理 |
| 第三關 碎裂崖 | 近戰 + 遠程 + 會蓄力衝撞的精英怪（地上畫出紅色衝撞線，撞完會暈、吃雙倍傷害） |
| Boss 房 | 方塊巨怪先在地上標出 3×3 咬痕範圍再吃掉地板；咬完下巴搭在洞的南緣、核心露出幾秒，所有人上前打；下一次露核前先來一小波雜兵 |

- **共用擊倒計數**：每隻敵人倒下只算一次（掉海也算），誰補最後一下都一樣。累計達 8 / 20 / 36（兩人基準，依人數縮放）記下一次升級，**當波清完**才在大螢幕結算選技能。
- **選技能**：大螢幕每人一欄四個選項，手機**左傾 / 右傾**切換、**回正停住 1.2 秒**確認（鍵盤 A / D）；25 秒沒選就用目前游標。可以多人選同一個，已有的技能會變成強化 Lv2。
- **倒地與救援**：血量 4 格，歸零倒地；隊友靠近站 2 秒救起（護友更快）。全員倒地就輸。單人沒有隊友，倒地 5 秒後自己爬起，最多 3 次。每清一波全員回 1 格血，過關回滿。
- **人數調整**：每波敵人數、擊倒門檻、Boss 血量與露核秒數都依人數調整（`server/island.js` 的 `COUNT_SCALE`、`KILL_SCALE`、`BOSS_HP_SCALE`、`EXPOSE_DUR`）。
- **電腦隊友**：大廳手機按「補滿電腦隊友」或鍵盤 `B`，空位會由電腦補滿（計入人數，所以一個人也能打四人規模）。電腦會追最近的敵人（遠程優先）、避開 Boss 咬痕與衝撞線、優先救倒地的真人、露核心時上前，升級時依各自偏好選技能；真人中途加入會接手電腦的位置。判斷寫在 `botThink()`，和測試裡的腳本玩家同一套。

## 技能池

| 技能 | 觸發 | Lv2 |
|---|---|---|
| 震地 | 跳躍落地時把身邊 2.2 格內的小怪打退並造成傷害 | 範圍 3、傷害加倍 |
| 連鎖槌 | 每次敲中的敵人把傷害傳給 3 格內最近的另一隻 | 傳給兩隻 |
| 旋風步 | 持續朝同一方向走 1.2 秒會短暫加速 1.5 倍並推開路上的小怪 | 0.8 秒觸發、傷害加倍 |
| 護友 | 救援倒地隊友 1 秒完成，救起後兩人獲得 6 秒護盾（擋 1 下） | 護盾兩層、救起回滿血 |

## 控制

| 動作 | 手機 | 鍵盤除錯（顯示端） |
|---|---|---|
| 走位 | 雙軸傾斜（死區 6°、24° 全速，預設不動 = 往前傾 45°；快速抬過 90° 再放回即重新校正） | P1 WASD ／ P2 方向鍵 ／ P3 IJKL ／ P4 TFGH |
| 跳躍 | 手腕短促上抬 | P1 空白 ／ P2 Enter ／ P3 U ／ P4 Y |
| 攻擊 | 自動：攻擊距離內敲最近的敵人（向前短推可立刻出手） | 自動 |
| 開始 / 再來一局 | 向前短推 | E |
| 其他 | 「重新校正持握」、手勢靈敏度、前後 / 左右反轉、備援按鈕、大廳「補滿電腦隊友」 | 1～4 加入鍵盤玩家、B 補滿電腦隊友、R 重開、F 全螢幕 |

手勢判定（`public/island/controller.js`）：去重力加速度轉到世界座標，超過門檻進入「爆發」，累積加速階段的向量，
峰值一過就分類——**向上分量占優**為跳躍、**沿手機前方的水平分量占優**為短推，其餘忽略。**手機必須用 HTTPS 連線**，
iPhone Safari 與 Android Chrome 在 HTTP 下都不給感測器資料（見上方 mkcert 說明）。

## 美術模型

模型放在 `public/assets/island/`（glTF Y-up，角色與怪物面向 +Z；交接文件 `docs/ISLAND_HANDOFF.md`、`docs/ISLAND_COOP_ART.md`），
顯示端啟動時載入，**缺檔時自動退回程式建立的同名節點替代模型**：

| 檔案 | 接法 |
|---|---|
| `repairer-blue/orange/purple/green.glb` | P1～P4，原點在腳下、高 1.10，顯示端放大 1.25。`Arm_L/R`、`Leg_L/R` 跑跳；敲擊時右臂先往後上舉再往前下揮 |
| `mob-melee.glb` | 近戰小怪。`Claw_L/R` 蓄力時往後收、出爪時往前；`Foot_L/R` 走路、`Head` 低頭 |
| `mob-ranged.glb` | 遠程怪。`HoverBody` 上下浮動、`Fin_L/R` 擺動；蓄力時 `ProjectileSocket` 發光，投射物用 `enemy-orb.glb` |
| `mob-charger.glb` | 衝撞精英。`RamGuard` 蓄力下壓、衝撞回彈；`ChargeLight` 蓄力閃爍；地上另畫紅色衝撞線 |
| `chomp-boss.glb` | `UpperJaw`/`Jaw` 張嘴，`Core` 只在露核時可見並脈動發光；伺服器 `BOSS_ANCHOR`/`CORE_OFFSET` 依節點位置設定 |
| `stage-gate.glb` | 北邊的關卡門，過關時 `GateCenter` 處的光幕亮起；Boss 房時由 Boss 取代 |
| `upgrade-shrine.glb` | 升級時在島中央出現，`CrystalPivot` 旋轉、外擴光圈 |
| `skills/*.svg` | 技能圖示，升級選單與玩家卡上與名稱一起顯示 |
| `ground-tile.glb` | 寬 1.44、原點在頂面，1.5 間距排格；Boss 咬掉的地板 18 秒後長回 |

Three.js 由伺服器從 `node_modules/three` 以 `/vendor/three/…` 提供，區網沒有對外網路也能用。

## 測試

```bash
npm test
```

`test/island-loop.test.mjs` 用腳本玩家在無頭模擬裡跑完整一局：兩人擊倒同一波怪 → 共用計數達標 → 兩人各選不同技能
（震地、連鎖槌）→ 同進 Boss 房 → 勝利；另外驗證單人縮減規模與自動爬起、倒地救援 / 護友 / 全員倒地失敗、四人加入。
腳本玩家不會閃投射物，偶爾會輸，測試允許重試三次。
